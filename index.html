ENGINEERING PRACTICE · LIVE · FOUR CASE STUDIES

How the Work Gets Built Safely

Automation, Enforcement, Disclosure Control, and Parallel Sessions Across a Multi-Repo Codebase

Engineering Problem A small team running daily AI coding sessions across several repositories has two exposures nobody else will catch: conventions that hold only while someone remembers them, and patentable mechanism sitting one paragraph away from every public draft. The layer that catches them has to work on everyone's machine, not just the one it was written on.

Four write-ups on the layer around the code. A lifecycle-hook layer that makes safety automatic; a register and ledger that convert remembered conventions into checks that go red; a staged pipeline that controls what leaves a patent-pending repo; and an orchestration pattern for running several coding sessions at once without them colliding. Each one documents where it has failed.

LIVE · ALL FOUR OPEN NOW
  • Lifecycle hooks across every stage of a session, on three operating systems
  • Fail-open by default, fail-closed where a false pass is unrecoverable — and never fail-silent
  • Every discipline classified enforced, narrated, or hybrid — and tracked
  • A hard bar before a check may be called "enforced"
  • Checks that turned out never to fire — found, fixed, published
  • A staged disclosure pipeline, weighted by audience, gaps named
  • Parallel coding sessions leased by write-surface, with every serial resource routed through one writer
Bash Python Git Claude Code Process Design

PROJECT_03

Emergent Media Manager

Local-First Medical Data Layer

Clinical Problem Unstructured medical data — EKGs, imaging, documents — lives in silos, arrives in inconsistent formats, and requires manual review to extract actionable clinical meaning.

Multi-modal ingestion pipeline that converts raw clinical media into structured, searchable knowledge. Files stay on the local device by default rather than being uploaded to a server.

  • Multi-modal analysis: EKG, MRI, clinical imagery
  • Extracts ICD-10/CPT candidates from document context, flagged for coder review — it never assigns a billable code
  • Egress guard: five identifier patterns (SSN, MRN, date of birth, phone, patient-name field) block cloud upload and force the request to a local model instead
  • Dataset nutrition label per collection: completeness, author and category distribution, a privacy-risk heuristic
  • OMOP and CDISC SDTM mapping · File System Access API for local-first storage
React Gemini AI Local-First

Prototype, built and tested against synthetic data only. Be precise about what the guard is: it detects and blocks, it does not de-identify, and five patterns touch five of the eighteen Safe Harbor identifier categories — useful as a fail-closed egress control, not a compliance claim. HIPAA obligations attach to a covered entity or business associate, not to software.
